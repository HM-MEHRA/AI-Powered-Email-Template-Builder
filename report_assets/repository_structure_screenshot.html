Full-Stack Project Repository

Clean project layout showing the React frontend and Django backend. The backend highlights the core API files used for request handling, URL routing, and database models.

Frontend

React Application

The `src` folder contains reusable components, service APIs, application state, and UI flow for login, generation, templates, editor, preview, history, and account pages.

Backend

Django API

The `templates_api` app contains `views.py`, `urls.py`, and `models.py`, which power authentication, email generation, template management, and history storage.

Database

SQLite Storage

The `db.sqlite3` file stores user accounts, generated email history, saved templates, favorites, sharing data, and archive state during development.

Deployment

Docker Support

Dockerfiles and compose configuration define separate frontend and backend services, making the full-stack project easier to run and deploy.
